# Fluent Tests

Write fluent, human-readable tests that read like plain English while using
the type system. Use when writing tests, improving test readability,
designing matchers, or structuring Given-When-Then patterns.

SurMap's suite is Python/pytest: start with
`references/generic-guidelines.md`, then `references/python/pytest.md` for
the idiomatic examples (builders over `src/surmap/types.py` contracts,
fakes at the SLAM adapter seam).

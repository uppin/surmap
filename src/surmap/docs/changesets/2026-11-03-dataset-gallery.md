# Dataset gallery: all public KITTI raw drives, split RTAB-Map/SAM agent tools

**Date:** 2026-11-03
**Type:** Feature
**Packages:** surmap

An extensible dataset catalogue (`surmap.demo.gallery` over
`surmap.demo.datasets.DATASETS`) gave every registered dataset a provider,
licence (name, URL, attribution), grey/colour modality, location and GPS
centre; a new data source now joins the gallery, the agent tools and the
demo picker by registering one `DatasetSpec`.

All 156 public KITTI raw drives were registered in grey (`image_00/01`)
and colour (`image_02/03`), 312 KITTI entries sharing one download per
drive, generated by `scripts/list_kitti_raw.py` from the public
`avg-kitti` bucket into `surmap.demo.kitti_raw` (size pinned, SHA-256
learned on first fetch; the hand-pinned drive 0009 keeps its upfront
SHA). Preparing a KITTI drive extracts its `oxts` GPS fixes to
`gps_track.json`; colour display frames stay colour for SAM.

The agent gained split dataset tools (`list_datasets`, `get_dataset`,
`prepare_dataset`, `run_rtabmap`, `run_sam_on_dataset`) beside the
combined `run_demo`, plus `GET /datasets` and
`GET /datasets/<id>/thumbnail.jpg`. The chat page's dataset gallery
became its own searchable screen (`?screen=gallery`) with thumbnail,
licence and GPS map preview per card; run buttons return to chat and
start the agent turn.

Wrap notes: `handlers.py` crossed 500 lines in this PR and was split
(`dataset_handlers.py`, verbatim move, same green). `datasets.py` was
already oversized and grew further; its split is recorded in
`src/surmap/docs/code-issues/oversized-file-demo-datasets.md`.
`demo/server.py` grew by 6 lines; its seams remain in its existing
oversized record for a dedicated restructure.

Tests: full suite 1709 passed, 33 skipped; web 112 passed; ruff, ruff
format and strict mypy clean; CI green on Python 3.11 and 3.12.

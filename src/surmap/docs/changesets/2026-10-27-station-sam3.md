# Station SAM 3.1 segmentation

**Date:** 2026-10-27
**Type:** Feature
**Packages:** surmap

Added the station's real segmentation behind the `SamDetector`
port: `surmap.survey.sam3` with `OnnxSam3Session` (ONNX Runtime —
CUDA execution provider on the station GPU, CPU elsewhere) and
`Sam3Detector` (preprocessing, session calls, mask→box/polygon
post-processing). The station process selects it with
`--detector sam3 --sam3-model <onnx> [--sam3-device cuda|cpu|auto]`.

Same runtime in tests, by construction: there is no test-only
detector path. Tests execute a tiny fake SAM3 ONNX graph
(`tests/fixtures/sam3_fake/fake_sam3.onnx`, generated by
`scripts/make_fake_sam3_model.py`) through the identical session and
adapter code on the CPU provider; production swaps only the model
file and the provider. The real SAM 3.1 checkpoint is license-gated
and large, so exporting it to the documented ONNX contract
(`image` → `masks`, `scores`) is a station provisioning step, not a
CI fetch.

Verification: session/detector unit tests on CPU (provider asserted,
bright-region box/polygon, dark-frame empty), plus
`tests/test_survey_station_sam3_e2e.py` — real station socket server
and real ONNX Runtime segmenting a moving bright box across six
frames, boxes following it, server closed afterwards.

# Initial discovery — simulation preview on-board detections

## Combined Conclusions

- The live sim stream (`?bridge=` page → `surmap.simulation.bevy_bridge` → `FleetPerception`)
  runs, per drone session, RTAB-Map (`StreamingBackend`) and a SAM segmentation sink
  (`SamSegmentationSink`, counts only). No on-board detector runs on it, and no agent tool picks
  one: `onboard_model` exists only on `run_demo` / `run_rtabmap` (`agent/tools/workspace.py`,
  `agent/tools/onboard.py` `OnboardModels`).
- `OnboardModels.source(model)` builds a fresh `DetectionSource` (Coral CPU twin + `IouTracker`);
  `detect_tracked(frame_id, rgb)` returns `TrackedDetection(label, score, box_xyxy, track_id,
  frame_id)`. `resolve()` maps `None`/`"none"`/name, raising `ValueError` for unknown names;
  `source()` raises `OnboardUnavailable` when the station lacks the files.
- The wire pairs are grey8 (`bevy_wire.BevyPair.left_data`); the detector needs HxWx3 RGB, so the
  grey left frame is stacked to three channels.
- `bevy_bridge.serve_bevy_bridge` runs `handle` in `asyncio.to_thread`, so a synchronous detection
  inside `DroneSession.process` does not block the event loop; it makes the detections arrive in
  the same `status` reply as their pair.
- `#142` added `BridgeStatus.odometry` and the preview's `HeldFrames` / `FpvFrame`
  (`examples/bevy-sitl-poc/src/preview.rs`, `fleet/bridge_wasm.rs`, `fleet/stream.rs`
  `parse_odometry`). The FPV shows a held frame once its odometry comes back. Detections for frame
  k arrive in pair k's reply, never later than k's odometry, so the page keeps recent detections
  by frame id and attaches them when it builds `FpvFrame`.
- The demo page's labels: `src/surmap/demo/view_math.py` `layoutCards` (candidates just above /
  below / left / right of the box, then a 4 px grid; skip any overlapping a placed card within
  `CARD_GAP_PX`; score = distance to the box (min the gap) + 1e4 if it covers the box + tiny
  centring terms; smallest boxes placed first; leader from the card's nearest edge point to the
  object's anchor), drawn by `sam_depth.py` `drawSamCards` (dark card, coloured border, leader
  with a 3 px dot at each end). Constants: margin 4, gap 4, grid 4.
- Bevy 0.18 UI text uses `Text` + `TextFont { font_size }` + `TextColor` (`ui.rs`); the default
  font is FiraMono (monospace), so a card's width can be estimated from its character count.
- Fleet tools: `proto/surmap/agent/v1/fleet_tools.proto`, regenerated by
  `scripts/gen_agent_rpc.py`; handlers in `agent/tools/fleet_handlers.py`, registered in
  `agent/server/app.py` (`DroneMapStatus` is bound beside `fleet_tool_handlers` with the
  `PerceptionRegistry`). `onboard_models(config)` in `app.py` builds the station's models.

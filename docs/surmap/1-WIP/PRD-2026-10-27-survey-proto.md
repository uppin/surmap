# Survey streaming proto contracts — PRD

**Date**: 2026-10-27
**PRD Type**: Enhancement

## Affected Features

- **Primary Feature**: Survey data APIs (docs/architecture.md §10) — first
  concrete wire contract for the Board (CM5) and GPU (station) APIs.
- **Related Feature**: ConnectRPC serving kit (docs/connectrpc.md) — gains
  its first product service descriptor.

## Summary

Define `surmap.survey.v1` in protobuf: two BIDI services (CM5 survey,
station SAM), the shared raw-frame/calibration input, the incremental
point/video output with int32 designations, and the station detection
vector. Also remove the unavailable `overstack` epic tooling from the
stack workflow docs, as directed for this node.

## Background

Architecture §10 names a Board API and a GPU API but no wire format exists.
Both machines must speak the same frame/calibration input so simulation
and replay are indistinguishable from flight data (§2.3).

## Proposed Changes

### What's Changing

- New proto package `surmap.survey.v1` with `Cm5SurveyService` and
  `StationSamService`, both BIDI streaming.
- Designations: `1` = RTAB-Map scene, `2`/`3` = video channels 0/1,
  objects `>= 100` (`100 + track_id`), `0` = unspecified.
- Generated Python bindings checked in, regenerated by a script like
  `scripts/gen_socket_rpc.py`.
- `.agents/` stack docs no longer reference overstack or an epic DAG CLI.

### What's Staying the Same

- `surmap.transport.v1` socket framing; `surmap.rpc` kit unchanged.
- Domain dataclasses in `surmap.types`; no flight-command surface of any
  kind (§1 scope boundary).

## Impact Analysis

### Technical Impact

- One new proto file, one generation script, generated bindings, and a
  small Python designation-helpers module. Servers land in later nodes.

### User Impact

- None yet — contracts only; nothing is served until n4/n5.

## Acceptance Criteria

- [ ] Both BIDI services, all messages, and designation helpers are
      defined and importable from the generated bindings.
- [ ] `grep -rn overstack .agents/` returns no matches.
- [ ] Existing suite still passes (`uv run pytest -q`, `uv run mypy`).
